# Shared contract

This directory is the language-neutral contract for the JavaScript/Bun and Python `unbun cc` implementations. The normative sources are [`dual-implementation-spec.md`](../docs/dual-implementation-spec.md) and [`shared-store-format.md`](../docs/shared-store-format.md).

## Schemas

The files in `schemas/` use JSON Schema Draft 2020-12 and stable `$id` values. Every public object has `schema_version: 1`; store manifests also have a fixed `schema` identity. Readers must reject missing required fields, wrong types, unknown schema identities, and schema versions other than `1`.

Schemas intentionally leave `additionalProperties` enabled. A reader may ignore fields added as optional observations within v1, but it must still validate every known field it consumes. Baseline and snapshot blob fields are restricted to their exact `blobs/<sha256>.<suffix>` form. Other relative asset paths must reject absolute paths, backslashes, and `..` path segments.

`schemas/exact-replay-result.schema.json` freezes the Phase 1 PoC process output. Unsupported skeletons and unreplayable substates must report `supported=false`, `byte_equal=false`, a null expected hash, and `not_implemented`, `unsupported_format`, or `substate_unreplayable`. A supported success must provide both hashes, report full-byte equality, and have no error. A supported proof rejection provides the replayed expected hash, reports `byte_equal=false`, and uses `baseline_stale_build`; hash equality alone is not the acceptance oracle.

## Vectors

`vectors/error-codes-v1.json` freezes the code, exit severity, and semantic meaning from shared store format section 12. Human-readable runtime messages are not golden output.

`vectors/canonical-path-v1.json` freezes canonical path and `path_key` examples. `path_key` is the lowercase SHA-256 hex digest of the canonical path encoded as UTF-8. POSIX cases preserve case after absolute-path and symlink resolution. Windows cases remove the extended-length prefix, replace backslashes with `/`, and lowercase ASCII `A-Z` only. All canonical results are NFC-normalized.

Dynamic absolute temporary paths, timestamps, PIDs, hostnames, and lock tokens must be replaced with typed placeholders before public golden comparison. These vector files contain only fixed protocol examples and are not generated by either patch implementation during tests.

## Inventory

Exact, machine-checkable counts (so coverage matrices don't miscount — review L2B-07):

| Group | Count | Files |
|---|---|---|
| `schemas/*.json` | 10 | target, baseline, snapshot, lock-owner, quarantine, transaction-scenario, status, error, write-envelope, exact-replay-result |
| `vectors/*.json` (top level) | 4 | canonical-path-v1, transaction-v1, error-codes-v1, platform-writes-v1 |
| `vectors/*/` (subdirs) | 4 | feature-claude-v1, known-bad-v1, lineage-v1, store-v1 |
| `vectors/**/fixtures/*.json` | 14 | payload fixtures across the 4 subdirs |
| `vectors/*/manifest.json` | 4 | one provenance/hash manifest per subdir |
| `golden/claude-v1/*.bin` | 2 | synthetic-2.1.175-{clean,all-patched} (pinned by `golden/SHA256SUMS`) |

Both implementations consume these: the JavaScript/Bun suite and the Python suite each load the schemas (JSON Schema validation), freeze the full error catalog, verify the golden `SHA256SUMS`, and check every manifest's fixture size/hash. See `python/cc-patch/tests/test_contract_consumption.py` for the Python side.

## Validation

Run the narrow contract suite with:

```bash
bun test test/contract/schema.test.mjs test/contract/exact-replay-harness.test.mjs
uv run --directory python/cc-patch pytest tests/test_contract_consumption.py tests/test_models.py
```

The suite uses Ajv rather than a project-specific validator. It verifies valid examples, malformed examples, forward-compatible unknown fields, the complete error catalog, canonical path digests, pinned exact replay fixtures, temporary-copy drift rejection, and both explicit PoC skeleton boundaries.
